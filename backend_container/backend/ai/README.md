# AI Module for Medical Specialty Classification

This AI module provides encoder-agnostic text classification for medical transcriptions using Hugging Face Transformers. It trains a classifier to predict medical specialties from transcription text and includes inference capabilities for real-time predictions.

## Overview

The module supports various pre-trained encoders (e.g., BERT, RoBERTa, ClinicalBERT) and offers two classification architectures: an advanced model that fine-tunes encoder layers and a simple model that freezes the encoder. It handles class imbalance with Focal Loss, class weights, and label smoothing, ensuring robust performance across medical specialties.

## Features

- **Encoder Agnostic**: Compatible with any Hugging Face model via `AutoModel` and `AutoTokenizer`.
- **Two Classifier Heads**:
  - **Advanced**: Partially fine-tunes the encoder's last layers and uses a deeper classification head.
  - **Simple**: Freezes the encoder and trains a lightweight head for faster training.
- **Smart Pooling**: Automatically uses `pooler_output` when available; falls back to masked mean pooling.
- **Imbalance Handling**: Employs Focal Loss with optional class weights and label smoothing.
- **Deterministic Mapping**: Sorts specialties for consistent label encoding.
- **Mixed Precision Training**: Supports CUDA for accelerated training.
- **Portable Inference**: Saves encoder components for easy deployment.

## Configuration

Configuration is managed via `config/config.py` in the project root. Key classes:

- **TrainingConfig**:
  - `MODEL_NAME`: Pre-trained encoder (e.g., `bert-base-uncased`, `allenai/biomed_roberta_base`)
  - `MAX_LENGTH`: Maximum token sequence length (default: 512)
  - `EPOCHS`: Number of training epochs
  - `MODEL_TYPE`: `'simple'` or `'advanced'`
  - `NUM_LABELS`: Number of medical specialties (default: 40)
  - `DROPOUT_RATE`: Dropout probability for classification head
  - `LABEL_SMOOTHING`: Label smoothing factor
  - `FREEZE_LAYERS`: Layers to freeze in advanced model (default: last 3)

- **InferenceConfig**:
  - `MODEL_PATH`: Path to trained checkpoint directory
  - `MAX_LENGTH`: Tokenization length for inference

## Data Pipeline

- **Input Data**: CSV file (e.g., `mtsamples.csv`) with columns `text` and `medical_specialty`.
- **Label Mapping**: Automatically generated by sorting unique specialties; saved as `label_mapping.json`.
- **Tokenization**: Uses `AutoTokenizer` to encode text into `input_ids` and `attention_mask`. Removes `token_type_ids` for RoBERTa compatibility.

## Models

Models are built using `AutoModel` for encoders. Pooling strategy:
- Prefers `outputs.pooler_output` if available.
- Falls back to mean pooling of `last_hidden_state` masked by attention.

Loss function: Focal Loss with configurable `alpha` and `gamma`, plus optional class weights and label smoothing.

### Advanced Classifier
- Fine-tunes the encoder's last layers while freezing earlier ones.
- Classification head: Batch normalization, ReLU activation, dropout, and linear layer.

### Simple Classifier
- Freezes the entire encoder.
- Lightweight head: Single linear layer with dropout.

## Training

Run training from the project root:

```bash
python -m backend.ai.training.train
```

Or programmatically:

```python
from backend.ai.data import load_medical_data, prepare_data
from backend.ai.training import train_epoch, validate
from backend.ai.models import get_model

# Load data
df = load_medical_data('training_data/mtsamples.csv')
train_loader, val_loader, tokenizer, labels = prepare_data(df)

# Build model
model = get_model('advanced', num_labels=40)

# Train and validate
train_loss, time_taken = train_epoch(model, train_loader, optimizer, criterion, device)
val_acc, val_loss, f1_macro, f1_weighted, cm = validate(model, val_loader, labels, device)
```

Training saves checkpoints to `checkpoints/epoch_X/` and `checkpoints/best/`, including:
- Model weights (`pytorch_model.bin`)
- Encoder files (`encoder_base/`)
- Label mapping (`label_mapping.json`)

**Tips**:
- Reduce `MAX_LENGTH` or batch size for limited GPU memory.
- Tune Focal Loss parameters for imbalanced datasets.
- Adjust `FREEZE_LAYERS` in advanced mode for performance trade-offs.

## Evaluation

Metrics reported during training/validation:
- **Accuracy**: Overall correct prediction rate.
- **F1 Macro**: Average F1 score across classes (equal weighting).
- **F1 Weighted**: F1 score weighted by class support.

Use F1 Macro for balanced evaluation across specialties.

## Inference

Perform predictions using:

```bash
python -m backend.ai.inference.inference
```

Programmatic usage:

```python
from backend.ai.inference import load_trained_model, predict
from transformers import AutoTokenizer
import torch

model_path = "checkpoints/best"
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

model, id_to_label = load_trained_model(model_path, device)
tokenizer = AutoTokenizer.from_pretrained(f"{model_path}/encoder_base")

text = "Patient presents with shortness of breath and wheezing."
predicted_label, confidence, top5_candidates = predict(text, model, tokenizer, id_to_label, device)

print(f"Predicted Specialty: {predicted_label}")
print(f"Confidence: {confidence:.2%}")
print("Top 5 Candidates:")
for label, prob in top5_candidates:
    print(f"  - {label}: {prob:.2%}")
```

Inference loads the model and tokenizer from the checkpoint, tokenizes input, and returns predictions with confidence scores.

## Troubleshooting

- **Import Errors**: Run from project root; verify `__init__.py` files exist.
- **Tokenizer Issues**: Ensure `encoder_base/` is in the checkpoint; falls back to `bert_base/` or default.
- **CUDA Out of Memory**: Reduce `MAX_LENGTH`, batch size, or use gradient accumulation.
- **Poor Performance**: Try biomedical models (e.g., `allenai/biomed_roberta_base`), adjust Focal Loss, or increase epochs.
- **Module Not Found**: Confirm all dependencies are installed and paths are correct.
