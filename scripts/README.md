## Available Scripts

### diagnose.py
Comprehensive diagnostic script for validating model, data, and system setup.

```bash
python scripts/diagnose.py
```

Checks:
- Data loading and statistics
- Label distribution and encoding
- Text quality metrics
- Tokenization
- Model creation and parameters
- Forward pass functionality
- Class weight calculation
